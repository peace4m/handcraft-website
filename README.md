Wood Craft Website
A responsive, handcrafted-themed web project built to showcase traditional wooden products with modern design elements. This project focuses on a clean user interface, smooth animations, and an engaging user experience for potential customers.

🚀 Features
Responsive Design: Built using Bootstrap 5 to ensure it looks great on mobile, tablet, and desktop devices.

Animations: Uses AOS (Animate On Scroll) for professional entrance animations.

Interactive UI: Includes custom CSS hover effects, card transitions, and a smooth-scrolling navigation.

Form Validation: Features a functional-style contact form to capture user inquiries.

Performance: Optimized with custom wood-themed CSS variables for consistent styling.

🛠️ Tech Stack
HTML5

CSS3 (with custom variables and keyframe animations)

Bootstrap 5

JavaScript (ES6+)

FontAwesome (for icons)

AOS (for scroll animations)

📦 How to Run Locally
Clone this repository to your machine.

Open index.html in your web browser.
